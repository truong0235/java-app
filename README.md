## thông tin đồ án
- java jdk 21
- database: mysql
## hướng dẫn biên dịch và chạy ứng dụng
- cài đặt java 21
- chạy mysql (sử dụng docker copmose hoặc nạp file kho.sql thủ công)
- đổi tên file Config.java.example thành Config.java (path: ./app/src/main/java/com/bat/utils/statics/), sửa thông tin tài khoản mysql nếu cần
- chạy dự án (./gradlew clean build run) (./gradlew.bat clean build run    nếu dùng windows)
